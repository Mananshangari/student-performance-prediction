# Student Performance Prediction

## Overview
This project uses machine learning to predict students' final grades based on academic and personal features.

## Objectives
- Explore student performance data using Python.
- Visualize patterns and relationships in the dataset.
- Build and evaluate a Linear Regression model.
- Compare predictions using different sets of input features.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Google Colab

## Models
- **Model A:** Predicts final grades using student background and other selected features.
- **Model B:** Also uses first-period (G1) and second-period (G2) grades.

## Evaluation
Models are evaluated using Mean Absolute Error (MAE) and the coefficient of determination (R²).

## How to Run
1. Open the notebook in Google Colab.
2. Run the cells from top to bottom.
3. Ensure the dataset is available as required by the notebook.

## Learning Outcomes
This project explores data analysis, data visualization, regression, feature selection, and model evaluation.
